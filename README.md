# ai-passport-dino

T-Rex Run 3D（[Priler/dino3d](https://github.com/Priler/dino3d)）在 ai-passport 硬件
（ESP32-C3 + ST7789P3 240×320，横屏游玩）上的移植。

## 从 ai-passport 参考的模式

| 模式 | 来源 | 本项目怎么用 |
| --- | --- | --- |
| BSP 组件整体复用 | `components/bsp` | 原样拷贝（未改 ai-passport 一行代码），提供显示/按键/音频驱动 |
| 直接驱动 esp_lcd 面板 | `bsp_display.h` 头文件注释鼓励的做法 | 游戏绕过 LVGL，`esp_lcd_panel_draw_bitmap()` 条带推屏 |
| 按键回调 + 电压轮询 | `bsp_button.h`（PRESS 事件 + `bsp_button_read_mv()`） | 跳跃用按下事件，下蹲用按住轮询 |
| 分区表与 flash 约束 | `partitions.csv`、`sdkconfig.defaults` | 原样沿用（cardid 保护区不动，8MB flash，3MB app 上限） |
| 构建体系 | `docs/development/engineering/build-and-test.md` | 同一套 `idf.py` 流程 |

为压缩体积，本项目的 BSP 副本做了两处裁剪（只改副本，不动原仓库）：
移除 LVGL 相关文件/依赖、移除 esp_lvgl_port 依赖；蓝牙在 sdkconfig 中关闭。
IDF 约束放宽为 `>=5.5.3` 以兼容本机 v6.1 工具链。

## 文件结构

```
ai-passport-dino/
├── CMakeLists.txt          # 工程入口
├── sdkconfig.defaults      # esp32c3 / 8MB / 关蓝牙 / 体积优化
├── partitions.csv          # 与 ai-passport 一致(cardid 保护区不动)
├── components/bsp/         # 从 ai-passport 拷贝并裁剪 LVGL
├── main/
│   ├── main.c              # 入口: NVS + 显示初始化 + 进游戏
│   ├── game.c/h            # 状态机(READY/RUNNING/PAUSED/GAME_OVER)、分数、速度、昼夜
│   ├── player.c/h          # 恐龙: 跑/跳/蹲动画、物理、碰撞盒
│   ├── obstacles.c/h       # 仙人掌群/翼龙: 生成规则、滚动、碰撞
│   ├── scenery.c/h         # 云、星星、地面斑点、滚动风滚草等装饰
│   ├── day_cycle.c/h       # 2 秒四阶段昼夜调色板插值
│   ├── dust.c/h            # 起跑/落地扬尘固定粒子池
│   ├── hud.c/h             # 3x5 像素字体计分板、GAME OVER、PAUSED
│   ├── render.c/h          # 条带式渲染器(320x24 条带, ~15KB DMA 内存)
│   ├── input.c/h           # 按键事件 + 按住轮询 + 冲突处理
│   ├── sfx.c/h             # 跳跃/死亡音效(合成方波, 独立任务播放)
│   └── sprites.c/h         # 自动生成的精灵表(勿手改)
└── tools/
    └── bake_sprites.js     # .vox 体素 → 8bpp 调色板精灵的烘焙脚本
```

## 构建与烧录

```sh
. /Users/lim/.espressif/v6.1/esp-idf/export.sh
idf.py set-target esp32c3
idf.py build flash monitor   # 串口按实际 -p PORT 指定
```

重新烘焙精灵（改了 dino3d 资源或投影参数后）：

```sh
node tools/bake_sprites.js   # .vox 体素 → 3D 像素精灵, 输出 main/sprites.[ch]
```

（另有 `tools/bake_sprites_2d.js` 是纯 2D 像素稿方案, 已不用于当前固件。）

## 操作说明

- **Up**：跳跃（按住跳得更高；空中按住 Down 速降）
- **跳跃缓冲**：落地前 80ms 内按下 Up，落地瞬间自动起跳
- **Down**：按住下蹲，松开站起；下蹲中不能起跳（与原版一致）
- **OK**：暂停 / 恢复
- **红心生命**：开局 3 颗红心（左上角）。撞到仙人掌/翼龙扣 1 颗，撞到的障碍碎裂消失，随后 1.5 秒无敌闪烁（期间再撞不扣心）。红心为 0 再撞才 GAME OVER
- **红心补给**：每 1000 分保底在路上刷一颗 + 每次生成障碍 2% 概率；满心 3 颗时不刷。70% 贴地 30% 低空（需起跳吃）
- **OK 长按**：进入/退出设置菜单
  - 列表态：Up/Down 选行，OK 单击进入该项配置
  - 配置态：Up 调高 / Down 调低（到顶/到底停住），OK 单击退出配置回到列表
  - `VOLUME`：0/20/40/60/80/100%；`LIGHT`：20/40/60/80/100%，立即生效
  - 设置期间 Up/Down/OK 全部与游戏隔离，不会触发跳跃/下蹲/暂停/音效
  - 设置写入 NVS，断电保留
- **游戏结束后**：按 Up / Down / OK 任意键重开
- **Power 键**：独立于 ADC 三键，不产生按键事件，天然不会触发重开

## 实现要点

- **资源 1:1 烘焙**：`bake_sprites.js` 直接解析原版 `.vox` 体素模型，按 45° 俯视斜投影(K=3)渲成 3D 像素精灵，含方向性明暗(顶面×1.3 亮/侧面×0.7 暗)；16bpp RGB565 直出。恐龙跑 8 帧、下蹲 8 帧、死亡帧、6 种仙人掌、翼龙 2 帧、地面装饰 + 远景树/小仙人掌(K=1~2 小号)全部来自原版模型。
- **画面**：四层纵深——天空(云视差 0.25×、夜间 14 颗错峰闪烁星星)、远场景带(树/远景仙人掌 0.45× 视差)、伪透视收拢的蓝河、近处跑道。首次起跳和每次落地有短促扬尘；风滚草以 1.15× 地速滚动并轻微弹跳。
- **渲染**：条带式(320×24), 16bpp 精灵 + 矩形命令重放。每条带推送前等待上一笔 SPI DMA 传输完成(传输完成回调 + 信号量), 避免覆写未发完的缓冲导致横条纹。
- **横屏方向**：`render.c` 里 `LANDSCAPE_LEFT` 宏选择纯旋转(1=270° 从左侧看, Power 一侧朝下; 0=90° 从右侧看)。注意 (swap=1,mx=1,my=1) 是旋转+水平镜像, 文字会变反, 不能用。颜色若红蓝互换, 把 `SWAP_BYTES` 改为 0。
- **手感数值**：分数 10 分/秒、每 100 分提速+闪烁、四档速度、跳跃初速随档位提高、按住跳跃键重力减小（boost）、空中按下速降、下蹲中禁跳——全部对齐原版 `player_manager.js` / `enemy_manager.js` / `score_manager.js` 的行为。K=3 尺寸下跳高 ~104px、空中 ~1.16s，最低速可跳过三连仙人掌簇；低速档最多 2 连保底。
- **碰撞**：AABB，恐龙碰撞盒内收约 30%，仙人掌/翼龙内收（翼龙翅膀不算），贴近原版"宽容"手感。
- **最高分**：NVS 持久化，断电不丢。

## 自测清单

- [ ] 跳跃：Up 短按小跳、按住大跳；奔跑中可跳；落地前 80ms 输入会缓冲
- [ ] 扬尘：首次起跳有较明显扬尘；普通起跳没有；落地有较小扬尘
- [ ] 下蹲：Down 按住蹲下（碰撞盒变矮）、松开站起；下蹲按 Up 不跳
- [ ] 速降：跳跃中按 Down 快速落地
- [ ] 暂停/恢复：OK 短按切换，画面冻结，分数不动
- [ ] 设置菜单：长按 OK 进入/退出；Up/Down 选行，OK 单击进入配置；配置态 Up 调高 / Down 调低，OK 退出；期间按键不触发游戏动作与音效；断电后设置保留
- [ ] 红心：开局 3 颗；撞障碍扣 1 颗且该障碍碎裂、无敌闪烁 1.5s；无敌期再撞不扣心；满心不吃心；0 心再撞才 GAME OVER
- [ ] 红心补给：1000 分保底出现；满心时不刷；贴地可直接吃、低空需跳吃
- [ ] 失败重开：心数归零 GAME OVER 后 Up/Down/OK 任意键重开；Power 键不重开
- [ ] 碰撞：0 心时碰到仙人掌/翼龙立即结束；擦边（视觉碰到但碰撞盒没碰到）不结束
- [ ] 分数：持续累加，每 100 分闪烁提示并提速
- [ ] 最高分：破纪录后写入，断电重启仍在
- [ ] 风滚草：以略快于地面的速度滚动并轻微弹跳，且不参与碰撞
- [ ] 昼夜切换：每 700 分昼夜交替，四个关键色在 2 秒内平滑过渡
- [ ] 夜晚星星：过渡后半段分批出现并错峰闪烁；暂停时冻结
- [ ] 翼龙：速度档 ≥1 且分数 ≥450 后出现，三种高度，扑翼动画

## 与原版无法 1:1 的差异

1. **真 3D → 伪 3D 精灵**：ESP32-C3 无 GPU，原版体素模型离线烘焙成固定视角的 3D 像素精灵。放弃雾、色调映射、SAO 等后处理。
2. **背景音乐**：只保留跳跃/死亡两个合成音效，原版 BGM 未移植（flash 与解码成本）。
3. **云**：像素矩形云，保留视差滚动。
4. **昼夜切换**：全场景使用四个关键调色阶段连续插值，仍不包含原版的动态光照与雾。
5. **GAME OVER**：3 倍像素字 + 黑色阴影居中显示。
