# 游戏操作与障碍扩展规范

本文档记录上/下键的扩展动作，以及障碍物的分类、尺寸和放置层约定。新增障碍或新增动作时，先按本文档定义交互，再补充实现与测试。

## 1. 输入动作扩展

| 输入 | 动作 | 典型用途 |
| --- | --- | --- |
| 短按上 | 小跳 | 矮障碍、小坑 |
| 长按上 | 高跳 | 宽坑、高障碍 |
| 空中短按上 | 二段跳 | 高台、连续障碍 |
| 空中长按上 | 滑翔/漂浮 | 翼龙、跨长坑 |
| 短按下 | 快速俯身 | 躲飞行敌人 |
| 长按下 | 滑铲 | 低矮通道 |
| 空中按下 | 速降/踩踏 | 踩敌人、快速落地 |
| 滑铲中按上 | 滑铲跳 | 连续低障碍 + 坑 |
| 落地瞬间按下 | 翻滚 | 短暂无敌、取消硬直 |
| 下 → 上快按 | 蓄力跳/滑铲跳 | 特殊地形 |
| 上 → 下快按 | 下砸 | 破坏脆弱地板 |

### 输入判定约定

- “短按/长按”由按下持续时间区分；阈值应集中定义，不要散落在各个障碍分支中。
- “空中”动作必须以玩家状态为准，不能仅依据按键顺序判断。
- 连招动作需要记录最近一次方向及时间窗口，并在窗口超时后清除。
- 新动作应明确是否消耗跳跃次数、是否改变碰撞盒，以及是否产生扬尘、音效或无敌帧。
- 当前固件已实现短按/长按跳跃语义、空中速降和落地前 80ms 跳跃缓冲；二段跳、滑翔、滑铲跳、翻滚、蓄力跳和下砸属于后续扩展接口。

## 2. 障碍分类与放置规范

| 类型 | 推荐操作 | 建议尺寸/范围 | 放置层与锚点 |
| --- | --- | --- | --- |
| 低障碍 | 短跳 | 高 16–24px | NEAR，底部 `y=216` |
| 中障碍 | 长跳/二段跳 | 高 32–48px | NEAR，底部 `y=216` |
| 高障碍 | 二段跳 | 高 48–64px | NEAR，底部 `y=216` |
| 头顶障碍 | 俯身/滑铲 | 底部 `y=168–184`，高 16–24px | NEAR |
| 宽坑 | 长按跳/二段跳 | 宽 48–96px | 地面缺口 |
| 飞行障碍 | 俯身或跳 | `y=150–190` | NEAR |
| 周期障碍 | 看时机跳/蹲 | 高 16–32px | NEAR |
| 可破坏 | 踩踏/冲刺 | 高 16–24px | NEAR |
| 环境机关 | 跳/蹲互动 | 不定 | NEAR/MID |

### 坐标与纵深约定

- 屏幕坐标为横屏 `320×240`，`y` 向下递增。
- `SKY`：`y=0–87`；只放天空、太阳/月亮、云和星星。
- `MID`：`y=88–159`；只放非碰撞装饰、场景地标和视差元素。
- `NEAR`：`y=160–239`；放玩家、会碰撞的障碍、地面缺口和前景元素。
- 普通地面障碍脚底统一锚定 `y=216`；玩家脚底也为 `y=216`。
- MID 元素不得参与碰撞，避免装饰误导玩家；障碍的碰撞盒应与显示精灵分开定义并写入测试。

## 3. 新增障碍的实现清单

新增障碍类型时，建议按以下顺序实现：

1. 在障碍类型枚举中增加类型，并定义显示精灵、帧数和锚点。
2. 在生成逻辑中定义出现分数、速度档、最小间距和场景限制。
3. 根据上表选择 NEAR/MID 放置层，明确底部或顶部锚点。
4. 单独定义碰撞盒；不要直接用精灵完整矩形代替碰撞盒。
5. 定义玩家应对动作：跳、蹲、速降、踩踏或连招，并注明失败后果。
6. 增加主机测试：生成概率、坐标范围、最小间距、碰撞盒和边界状态。
7. 在硬件上验证 80MHz SPI、局部刷新和障碍进入屏幕时的可反应提前量。

## 4. 当前障碍映射

| 当前对象 | 分类 | 当前操作 | 备注 |
| --- | --- | --- | --- |
| 场景仙人掌/岩柱/荆棘/熔岩口 | 低/中/高障碍 | 跳跃 | 仅 NEAR 障碍参与碰撞 |
| 翼龙 | 飞行障碍 | 俯身或跳跃 | 已包含低、中、高及头部高度档位 |

| 风滚草 | 环境装饰 | 无 | NEAR/MID 分层滚动，不参与碰撞 |

## 5. 峡谷场景障碍物

峡谷适合使用岩石、断崖、落石和低拱门等障碍。推荐首批实现：岩柱、裂隙、低拱门、落石。

| 障碍物 | 类型 | 操作 | 尺寸建议 | 说明 |
| --- | --- | --- | --- | --- |
| 岩柱 | 中/高障碍 | 跳/二段跳 | 高 24–48px | 已有 `canyon_spire` |
| 石笋 | 低障碍 | 短跳 | 高 16–24px | 可做 2 帧 |
| 裂隙 | 宽坑 | 长按跳 | 宽 48–80px | 地面缺口 |
| 断崖 | 宽坑 + 高台 | 二段跳 | 宽 64–96px | 落地要稳 |
| 低拱门 | 头顶障碍 | 滑铲 | 底部 `y=176` | 岩拱，必须滑铲 |
| 落石 | 定时掉落 | 跳/蹲 | 16–24px | 用地面阴影提示 |
| 滚石 | 移动障碍 | 跳 | 24–32px | 从右向左滚动 |
| 碎石堆 | 低障碍 | 跳/踩碎 | 16–24px | 可破坏 |
| 风蚀柱 | 高障碍 | 二段跳 | 40–56px | 比岩柱更细 |
| 悬垂岩 | 头顶障碍 | 滑铲 | 底部 `y=168` | 从顶部垂下 |

推荐组合：

```text
岩柱 → 裂隙 → 低拱门 → 岩柱
节奏：跳 → 长跳 → 滑铲 → 跳
```

## 6. 绿洲场景障碍物

绿洲适合使用水、植物、动物和泥潭等障碍。推荐首批实现：倒木、水池、低垂藤蔓、鳄鱼。

| 障碍物 | 类型 | 操作 | 尺寸建议 | 说明 |
| --- | --- | --- | --- | --- |
| 倒木 | 低障碍 | 跳 | 高 16–24px | 棕榈树干 |
| 低垂棕榈叶 | 头顶障碍 | 滑铲 | 底部 `y=176` | 从上方垂下 |
| 水池 | 宽坑 | 长跳 | 宽 48–80px | 踩入减速 |
| 泥潭 | 陷阱 | 跳 | 宽 32–48px | 踩入减速并下陷 |
| 荆棘藤蔓 | 低/中障碍 | 跳/滑铲 | 16–32px | 已有 `oasis_thorn` |
| 食人花 | 周期障碍 | 跳/蹲 | 24–32px | 张合动画 |
| 鳄鱼 | 定时障碍 | 跳 | 24–32px | 从水里冒出 |
| 蛇 | 地面移动 | 跳 | 高 8–16px | 左右游动 |
| 蜂群 | 飞行障碍 | 俯身 | 16–24px | `y=160–180` |

| 火山弹 | 掉落物 | 跳/蹲 | 16–24px | 用地面阴影提示 |

## 8. 与 bake 脚本的衔接

新增障碍素材优先使用 `tools/bake_sprites.js` 的 `addAsciiSprite` 生成离线精灵，并按场景调色板命名：

```js
// 峡谷
addAsciiSprite('canyon_arch_0', [...], 2, CANYON_ROCK_COLORS);
addAsciiSprite('canyon_crack_0', [...], 2, CANYON_ROCK_COLORS);
addAsciiSprite('canyon_rock_0', [...], 2, CANYON_ROCK_COLORS);

// 绿洲
addAsciiSprite('oasis_log_0', [...], 2, OASIS_BG);
addAsciiSprite('oasis_vine_0', [...], 2, OASIS_BG);
addAsciiSprite('oasis_pool_0', [...], 2, OASIS_BG);

// 火山
addAsciiSprite('volcano_lava_0', [...], 2, VOLCANO_BG);
addAsciiSprite('volcano_bomb_0', [...], 2, VOLCANO_BG);
addAsciiSprite('volcano_ash_0', [...], 2, VOLCANO_BG);
```

帧数建议：

- 静态障碍：1 帧。
- 周期障碍：2–4 帧。
- 掉落物：2 帧（空中、落地）。
- 可破坏障碍：2 帧（完整、碎裂）。

尺寸和锚点继续遵循以下规则：

- 地面障碍底部统一为 `y=216`。
- 头顶障碍底部为 `y=168–184`。
- 飞行障碍位于 `y=150–190`。
- 宽坑使用地面缺口表达，不使用普通精灵填充。

## 9. 难度与生成建议

每个场景建议准备：

- 地面低障碍 3 种。
- 地面中/高障碍 2 种。
- 头顶障碍 2 种。
- 宽坑 1 种。
- 飞行障碍 1 种。
- 周期机关 1 种。
- 可破坏障碍 1 种。

推荐生成权重：

| 类别 | 权重 |
| --- | ---: |
| 地面障碍 | 60% |
| 头顶障碍 | 20% |
| 飞行障碍 | 10% |
| 环境机关 | 10% |

随速度增加：

- 障碍间距逐步缩短，但必须保留玩家反应所需的最小提前量。
- 障碍组合概率增加。
- 周期障碍节奏变快，但不应缩短到无法通过的程度。

场景切换可采用每 800–1200 分切换一次，或按关卡固定场景。切换时应同步更换 MID 背景色和 NEAR 障碍池，过渡期间不要立即替换屏幕上已经生成的障碍。

## 10. 推荐实现顺序

### 第一版

- 峡谷：岩柱、裂隙、低拱门。
- 绿洲：倒木、水池、低垂藤蔓。
- 火山：岩浆池、喷气孔、火山灰云。

### 第二版

落石、滚石、鳄鱼、食人花、火山弹、间歇泉。

### 第三版

Boss 追逐：峡谷岩崩、绿洲鳄鱼群、火山熔岩流。

最稳妥的基础组合是：每个场景 4 个基础障碍 + 1 个周期机关 + 1 个飞行障碍；全部只用跳、长跳/二段跳和滑铲解决。可碰撞对象放在 NEAR，MID 只做剪影和非碰撞装饰。
